# Kanban — 1인 개발자용 Jira-like 보드

Node 서버 + SQLite. **모든 변경(생성·수정·드래그·삭제)은 그 즉시 서버 DB에 저장**되고, 열려 있는 다른 브라우저/기기에도 실시간으로 반영됩니다. 외부 의존성 없음(`npm install` 불필요).

## 실행
```bash
node server.js                 # http://127.0.0.1:3000
# 또는
npm start
```
Node **22.13 이상** 필요 (내장 `node:sqlite` 사용). 데이터는 `data/kanban.db` 에 저장됩니다.

| 환경변수 | 기본값 | 설명 |
|---|---|---|
| `PORT` | `3000` | 포트 |
| `HOST` | `127.0.0.1` | 외부 접속 허용 시 `0.0.0.0` |
| `DB_PATH` | `./data/kanban.db` | SQLite 파일 위치 |
| `KANBAN_PASSWORD` | (없음) | 설정하면 로그인 필요. **외부에 공개할 때는 반드시 설정** |

### 다른 기기(폰 등)에서 쓰기
- 같은 와이파이: `HOST=0.0.0.0 KANBAN_PASSWORD=비밀번호 node server.js` 후 `http://<PC IP>:3000`
- 인터넷 어디서나: 서버(VPS, 홈서버 등)에 Docker로 띄우고 HTTPS 리버스 프록시(Caddy, Nginx, Cloudflare Tunnel 등) 뒤에 두세요.

```bash
docker build -t kanban .
docker run -d --name kanban -p 3000:3000 -v kanban-data:/data -e KANBAN_PASSWORD=비밀번호 kanban
```
> SQLite 파일이 유지되려면 **영구 디스크(볼륨)** 가 있어야 합니다. 재시작 시 디스크가 초기화되는 무료 호스팅에서는 데이터가 사라집니다.

## 저장 방식
- 브라우저에서 변경 → 즉시 `POST /api/changes` → SQLite 트랜잭션으로 저장 → 다른 클라이언트에 `GET /api/events`(SSE)로 푸시
- 상단 표시: **저장됨 / 저장 중… / 연결 끊김 / 저장 실패**
- 서버가 잠깐 꺼져 있으면 변경을 메모리에 쌓아두고 자동 재시도 → 복구되면 전송 (저장 안 된 변경이 있으면 창 닫을 때 경고)
- 이슈 번호(`DEV-12`)는 서버가 발급하므로 여러 기기에서 동시에 만들어도 겹치지 않음
- 백업: `data/kanban.db` 파일 복사, 또는 메뉴 → JSON 내보내기. JSON 가져오기는 서버 데이터를 통째로 교체

## 기능
- **칸반 보드**: 드래그 앤 드롭(마우스·터치), 컬럼 추가/이름 변경(더블클릭)/이동/삭제, WIP 제한, 완료 컬럼 지정
- **이슈**: 유형(작업/스토리/버그/에픽), 우선순위 5단계, 라벨, 마감일(지남/임박 표시), 포인트, 체크리스트, 댓글, 상태 변경 이력, 마크다운 설명
- **빠른 생성**: 컬럼 하단에서 `로그인 버그 #auth #bug !high` → 라벨 `auth`, 유형 버그, 우선순위 높음
- **목록 보기**(정렬), **검색·필터**, 여러 프로젝트, 다크 모드, 삭제 실행 취소, `#DEV-12` 딥링크, CSV 내보내기

## 단축키
| 키 | 동작 |
|---|---|
| `C` | 새 이슈 |
| `/` | 검색 |
| `1`–`9` | 해당 컬럼에 빠른 추가 |
| `B` / `L` | 보드 / 목록 |
| `Esc` | 닫기 · 필터 지우기 |
| `Ctrl/⌘ + Enter` | 이슈 생성 · 댓글 저장 |
| `?` | 도움말 |
