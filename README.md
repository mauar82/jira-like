# Kanban — 1인 개발자용 Jira-like 보드

설치·빌드·서버·계정 없이 브라우저에서 바로 쓰는 칸반 보드입니다. `index.html`을 열면 끝.

## 기능
- **칸반 보드**: 드래그 앤 드롭(마우스·터치), 컬럼 추가/이름 변경(더블클릭)/이동/삭제, WIP 제한, 완료 컬럼 지정
- **이슈**: `DEV-12` 형식 키, 유형(작업/스토리/버그/에픽), 우선순위 5단계, 라벨, 마감일(지남/임박 표시), 포인트, 체크리스트, 댓글, 상태 변경 이력, 마크다운 설명
- **빠른 생성**: 컬럼 하단에서 `로그인 버그 #auth #bug !high` → 라벨 `auth`, 유형 버그, 우선순위 높음. Enter 연속 입력
- **목록 보기**: 키/요약/상태/우선순위/마감/업데이트로 정렬
- **검색·필터**: 텍스트, 유형, 우선순위, 라벨
- **여러 프로젝트**, 다크 모드, 삭제 실행 취소, `#DEV-12` 딥링크, 탭 간 동기화
- **백업**: JSON 내보내기/가져오기, CSV 내보내기(메뉴 ☰)

## 단축키
| 키 | 동작 |
|---|---|
| `C` | 새 이슈 |
| `/` | 검색 |
| `1`–`9` | 해당 컬럼에 빠른 추가 |
| `B` / `L` | 보드 / 목록 |
| `Esc` | 닫기 · 필터 지우기 |
| `Ctrl/⌘ + Enter` | 이슈 생성 · 댓글 저장 |
| `?` | 도움말 |

## 실행
- 로컬: `index.html`을 브라우저로 열기 (또는 `npx serve .`)
- 웹 배포: 저장소 **Settings → Pages → Source: GitHub Actions** 로 설정 후 `main`에 푸시하면 `.github/workflows/pages.yml`이 자동 배포

## 데이터
모든 데이터는 **그 브라우저의 localStorage**에 저장됩니다(서버로 전송 없음). 다른 기기/브라우저와는 공유되지 않으니 메뉴 → *JSON 백업 내보내기*로 주기적으로 백업하세요.
