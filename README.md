# Kanban — 1인 개발자용 Jira-like 보드

설치·빌드·서버·계정 없이 브라우저에서 바로 쓰는 칸반 보드입니다. `index.html`을 열면 끝.

## 기능
- **칸반 보드**: 드래그 앤 드롭(마우스·터치), 컬럼 추가/이름 변경(더블클릭)/이동/삭제, WIP 제한, 완료 컬럼 지정
- **이슈**: `DEV-12` 형식 키, 유형(작업/스토리/버그/에픽), 우선순위 5단계, 라벨, 마감일(지남/임박 표시), 포인트, 체크리스트, 댓글, 상태 변경 이력, 마크다운 설명
- **빠른 생성**: 컬럼 하단에서 `로그인 버그 #auth #bug !high` → 라벨 `auth`, 유형 버그, 우선순위 높음. Enter 연속 입력
- **목록 보기**: 키/요약/상태/우선순위/마감/업데이트로 정렬
- **검색·필터**: 텍스트, 유형, 우선순위, 라벨
- **여러 프로젝트**, 다크 모드, 삭제 실행 취소, `#DEV-12` 딥링크, 탭 간 동기화
- **기기 간 동기화**: 내 GitHub 저장소를 백엔드로 사용 (아래 참고)
- **백업**: JSON 내보내기/가져오기, CSV 내보내기(메뉴 ☰)

## 단축키
| 키 | 동작 |
|---|---|
| `C` | 새 이슈 |
| `/` | 검색 |
| `1`–`9` | 해당 컬럼에 빠른 추가 |
| `B` / `L` | 보드 / 목록 |
| `Esc` | 닫기 · 필터 지우기 |
| `Ctrl/⌘ + Enter` | 이슈 생성 · 댓글 저장 |
| `?` | 도움말 |

## 실행
- 로컬: `index.html`을 브라우저로 열기 (또는 `npx serve .`)
- 웹 배포: 저장소 **Settings → Pages → Source: GitHub Actions** 로 설정 후 `main`에 푸시하면 `.github/workflows/pages.yml`이 자동 배포

## 기기 간 동기화 (백엔드 = 내 GitHub 저장소)
별도 서버나 가입 없이, **내 GitHub 저장소의 JSON 파일 하나**를 백엔드로 씁니다. 변경할 때마다 커밋되므로 히스토리가 곧 백업입니다.

1. 데이터용 **비공개 저장소**를 만듭니다 (예: `kanban-data`). 빈 저장소여도 됩니다.
2. [Fine-grained 토큰 발급](https://github.com/settings/personal-access-tokens/new)
   - Repository access: **Only select repositories** → 위 저장소
   - Permissions → Repository → **Contents: Read and write**
3. 보드 우측 상단 **동기화** 버튼 → 소유자 / 저장소 / 토큰 입력 → 연결
4. 다른 기기에서도 같은 정보로 연결. 처음 연결하는 기기는 "원격 데이터로 대체"가 기본 체크되어 있어 샘플 데이터가 섞이지 않습니다.

동작 방식
- 변경 후 약 2.5초 뒤, 창에 다시 돌아올 때, 30초마다, 온라인 복귀 시 동기화
- 이슈·프로젝트 단위로 병합(최근 수정이 우선), 삭제는 툼스톤으로 전파, 오프라인에서 같은 번호가 생기면 나중 것을 재번호
- 동시에 쓰면(sha 충돌) 자동으로 다시 읽고 병합 후 재시도
- 오프라인이어도 로컬에서 계속 작업 가능 → 연결되면 합쳐짐

보안: 토큰은 그 브라우저의 localStorage에만 저장되고 `api.github.com`으로만 전송됩니다. 공용 PC에서는 사용 후 *연결 해제*(토큰 삭제)하세요. 토큰은 데이터 저장소 하나에만 권한을 주세요.

## 데이터
동기화를 켜지 않으면 데이터는 **그 브라우저의 localStorage**에만 저장됩니다. 메뉴 → *JSON 백업 내보내기*로 백업할 수 있습니다.
